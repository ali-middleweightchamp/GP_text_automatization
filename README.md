# GP Rewriter

![Python](https://img.shields.io/badge/Python-3.13-blue)
![OpenAI](https://img.shields.io/badge/OpenAI-GPT--4o--mini-green)
![Playwright](https://img.shields.io/badge/Playwright-automation-orange)

Автоматизация переписывания корпоративных описаний компаний на трёх языках с помощью AI.

## Что делает

- Авторизуется в веб-панели через Playwright
- Собирает записи по заданному статусу
- Переписывает описания через OpenAI GPT-4o-mini
- Генерирует тексты на русском, узбекском (латиница) и английском
- Автоматически определяет форму компании (ООО, АО, ИП и др.) и применяет правила форматирования
- Берёт официальные названия компаний с публичного сайта
- Сохраняет результат и меняет статус записи

## Технологии

- **Python 3.13** — основной язык
- **Playwright** — автоматизация браузера
- **OpenAI API** — GPT-4o-mini для генерации и перевода
- **python-dotenv** — конфигурация через .env

## Структура:
main.py      — оркестратор
auth.py      — авторизация
scraper.py   — сбор записей
rewriter.py  — генерация и перевод текстов
updater.py   — сохранение результатов
